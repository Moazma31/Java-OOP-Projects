# Java-OOP-Projects
Foundational and High-level OOP implemented in Java
This repository contains core programming and desktop application implementations built using Java to demonstrate foundational to advanced OOP concepts, terminal interactions, and Graphical User Interface (GUI) design patterns
**1**. Digital Bank Account Management System (BankApp.java)
A console-driven business logic model simulating secure, real-world banking operations.
**Key Principles:** Strict Encapsulation (securing balance variables through private fields), dynamic object instantiation, and balance limits checking logic.
**2.** AI-Guarded Intern Task Tracker (InternTracker.java)
A desktop GUI application built using Java Swing that serves as a database to track interns and their assigned domains.
**Core Architecture:** Java Swing (JFrame, JPanel, JList) for production-level interface layouts.
**Advanced Integration:** Features a rule-based mock AI validation engine that autonomously scans user input to detect and filter out corrupted or placeholder text strings.
